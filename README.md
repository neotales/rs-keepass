# rs-keepass

`neotales-keepass` reads, writes and edits KeePass KDBX vaults, and
`neotales-keepass-platform` adds the optional operating-system memory adapters.

By [x0craft](https://github.com/x0craft).

[![Neotales](https://github.com/neotales/brand/raw/main/assets/logo.png)](https://github.com/neotales/rs-keepass)

This repository is a virtual Cargo workspace. Both directories are shippable
crates and share one version:

| Crate | Directory | README |
| --- | --- | --- |
| `neotales-keepass` | `keepass/` | [keepass/README.md](keepass/README.md) |
| `neotales-keepass-platform` | `keepass-platform/` | [keepass-platform/README.md](keepass-platform/README.md) |
